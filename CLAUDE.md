## Caching

Browsers and Cloudflare keep files under `/assets/` longer than the pages, so after Round 8 a returning visitor could get the new page with the old stylesheet still in the cache, and the hero showed unstyled (10 November 2026). So every link on the pages to a stylesheet, script, picture, font or icon carries `?v=` and the first 10 characters of the file's sha256 (for example `/assets/site.css?v=e692e84da1`), and so do the fonts inside the stylesheet and og:image and twitter:image. A changed file gets a new address, so no browser or cache can pair a new page with an old file. `scripts/make_asset_versions.py` writes the versions (the fonts inside the stylesheet first, so the stylesheet's own version covers them); run it at every release. `check_copy.py` fails if a version is missing or does not match its file. The structured data keeps plain addresses. GitHub Pages ignores the query and serves the file as it stands.
